# Database Documentation

KisanSetu uses MySQL as its primary relational database. The schema is designed to manage users, agricultural market data, and digital sales receipts.

## Core Tables

### `users`
Stores farmer profiles and authentication data.
- **id**: Primary Key
- **full_name**, **mobile**, **email**: Contact information
- **password_hash**: Bcrypt hashed password
- **state**, **district**, **village**: Location details
- **latitude**, **longitude**: Precise coordinates for map and distance features
- **land_acres**: Farm size

### `market_prices`
Stores the daily APMC mandi prices fetched from `data.gov.in`. Acts as a cache to prevent hitting API rate limits.
- **id**: Primary Key
- **state**, **district**, **market**: Location details
- **commodity**, **variety**: Crop details
- **min_price**, **max_price**, **modal_price**: Pricing in INR
- **arrival_date**: Date of the price record

### `sales`
Stores digital sales receipts (J-Forms) generated by farmers.
- **id**: Primary Key
- **user_id**: Foreign Key to `users.id`
- **commodity**, **variety**, **quantity**, **unit**, **price_per_unit**, **total_amount**: Sale details
- **mandi_name**, **buyer_name**, **buyer_contact**: Buyer/Market details
- **receipt_id**: Unique string identifier (e.g., `REC-ABC1234`)

### `otp_verifications` (Optional/Future)
Designed to handle SMS OTP verifications for password resets or highly secure logins.

## Schema Location
The complete SQL schema definition can be found at `database/schema.sql`.
